# AUROVA — Menswear Shirting Website

A single-page landing site for AUROVA, a menswear shirting brand. Built as a fully self-contained HTML file (all images embedded as base64, no external dependencies except Google Fonts) — designed to be deployed as a static site with zero configuration.

## Live site
https://aurovaofficialwebcom.netlify.app

## Tech
- Plain HTML / CSS / vanilla JS (no build step, no framework)
- Google Fonts: Fraunces, Manrope, IBM Plex Mono
- Product photography embedded directly in the page as base64 data URIs

## Run locally
Just open `index.html` in any browser — no server needed.

## Deploy
Drag-and-drop `index.html` onto [Netlify Drop](https://app.netlify.com/drop), or push this repo and connect it to Netlify/Vercel/GitHub Pages.
